## 1. 栅栏缺口（FenceRing）

**文件**：`apps/web/src/farm3d/FarmScene.tsx` 第 758-786 行

**当前栅栏段（5 段顶 + 4 段左/右）**：
- 左侧 x=-2.35，4 段 z ∈ {-1.19, -0.425, 0.425, 1.19}，段宽 0.95
- 缺口选 **z ∈ [-0.425, 0.425] 区间**，去掉其中一段（z=-0.425 或 z=0.425），留 ~0.95m 宽

**改法**：把左侧 4 段循环改成 3 段，**跳过中间一段**：

```ts
// 当前
for (let i = 0; i < 4; i++) {
  const z = -hz + (2 * hz * (i + 0.5)) / 4  // i=0..3 → z=-1.19, -0.425, 0.425, 1.19
  list.push({ obj: make(), x: -hx, z, rotY: Math.PI / 2 }, ...)
}

// 改：去掉 i=1（z=-0.425），留 3 段在 z=-1.19, 0.425, 1.19
for (let i = 0; i < 4; i++) {
  if (i === 1) continue  // 跳过中间一段留缺口
  const z = -hz + (2 * hz * (i + 0.5)) / 4
  list.push({ obj: make(), x: -hx, z, rotY: Math.PI / 2 }, ...)
}
```

缺口覆盖 z 范围 [-0.425 - 0.475, -0.425 + 0.475] = [-0.9, 0.05] 约 0.95m 宽，z=0.3 在范围内 ✓

## 3. 新增 Warehouse.tsx

**文件**：`apps/web/src/farm3d/deco/Warehouse.tsx`（新）

**位置**：[-3.5, 0, -2.5]，cotage 正后方
- cottage 中心 z=2.5，cottage 旋转 +π/2 后 z 范围 [1.4, 3.6]
- 仓库放 z=-2.5，距离 cottage ~5m，中间留空地
- 与池塘（POND 在 z=-1.8）不冲突：warehouse 在 x=-3.5 偏左，pond 在 x=3.2 偏右

**外观设计**：木墙 + 茅草顶 + 大双木门（贴 cottage 风格但更敦实）

**导出常量**：
```ts
export const WAREHOUSE_POS: [number, number, number] = [-3.5, 0, -2.5]
```

**程序化几何**（参考 Cottage.tsx 但更敦实）：
- 底座：2.6w × 0.08h × 2.2d（比 cottage 大）
- 主体墙：2.4w × 1.2h × 2.0d（高度低、宽度大，仓库感）
- 大双木门（前面中间）：1.0w × 0.9h × 0.05d，深棕，门缝用更黑细条
- 屋顶：4 段锥，宽 1.8，矮 0.7（与 cottage 风格一致但稍矮）
- 「仓」字木牌（门上方）：0.4 × 0.25 米黄色板，模拟牌匾
- 通风窗：左右各一小窗（高 0.3 × 0.3）

**rotation**：仓库门朝 +x（朝 cottage/菜园方向），与 cottage 一致
```tsx
<group position={WAREHOUSE_POS} rotation={[0, Math.PI / 2, 0]}>
  <primitive object={group} />
</group>
```

**材质常量**：
```ts
const wallMat = new MeshLambertMaterial({ color: 0xb8924a })  // 比 cottage 略深（暗木色）
const roofMat = new MeshLambertMaterial({ color: 0x8b6914 })  // 茅草顶（同 cottage）
const doorMat = new MeshLambertMaterial({ color: 0x4a2c10 })  // 深棕大门
const signMat = new MeshLambertMaterial({ color: 0xf5e6a8 })  // 浅黄牌匾
```

**完整 buildWarehouse() 函数**（伪代码框架）：
```ts
function buildWarehouse(): Group {
  const g = new Group()
  // 底座
  const base = new Mesh(new BoxGeometry(2.6, 0.08, 2.2), baseMat)
  base.position.y = 0.04
  g.add(base)
  // 主体墙
  const wall = new Mesh(new BoxGeometry(2.4, 1.2, 2.0), wallMat)
  wall.position.y = 0.68
  g.add(wall)
  // 双木门（左扇 + 右扇，中间门缝）
  const doorL = new Mesh(new BoxGeometry(0.48, 0.85, 0.05), doorMat)
  doorL.position.set(-0.25, 0.485, 1.025)
  g.add(doorL)
  const doorR = new Mesh(new BoxGeometry(0.48, 0.85, 0.05), doorMat)
  doorR.position.set(0.25, 0.485, 1.025)
  g.add(doorR)
  // 门缝
  const seam = new Mesh(new BoxGeometry(0.04, 0.85, 0.06), new MeshLambertMaterial({ color: 0x1a0a00 }))
  seam.position.set(0, 0.485, 1.025)
  g.add(seam)
  // 门把手（两个圆球）
  const knobL = new Mesh(new SphereGeometry(0.04, 6, 6), signMat)
  knobL.position.set(-0.1, 0.5, 1.06)
  g.add(knobL)
  const knobR = new Mesh(new SphereGeometry(0.04, 6, 6), signMat)
  knobR.position.set(0.1, 0.5, 1.06)
  g.add(knobR)
  // 屋顶
  const roof = new Mesh(new ConeGeometry(1.8, 0.7, 4), roofMat)
  roof.position.y = 1.6
  roof.rotation.y = Math.PI / 4
  g.add(roof)
  // 牌匾（门上方）
  const sign = new Mesh(new BoxGeometry(0.5, 0.3, 0.05), signMat)
  sign.position.set(0, 1.0, 1.025)
  g.add(sign)
  // 通风窗（左右）
  const winMat = new MeshLambertMaterial({ color: 0xaad4ff, transparent: true, opacity: 0.6 })
  const winL = new Mesh(new BoxGeometry(0.3, 0.3, 0.05), winMat)
  winL.position.set(-0.85, 0.9, 1.025)
  g.add(winL)
  const winR = new Mesh(new BoxGeometry(0.3, 0.3, 0.05), winMat)
  winR.position.set(0.85, 0.9, 1.025)
  g.add(winR)
  return g
}
```
